### 7. R-09 — MCP nav badge uses the full capsule combo

Options: drop the glow (plain border), drop the uppercase, or drop the pill shape and let the word sit inline.

## LOW

### 8. R-05 — Features section is a bento grid
`app/_home/features.tsx:33` — `grid grid-cols-6` with cards spanning `col-span-4` and `col-span-2`. R-05 flags bento-grid-as-default. The content here does have variable weight (the big unified-index card has a real table preview; the small score card has an actual meter), so the varied sizing is justified — but there's no written note that this was a hierarchy decision rather than reaching for the pattern. One-line comment above the grid stating "card sizes reflect feature weight: index > score ≈ lookup, log is wide for timeline readability" closes this.

### 9. R-21 — Dark theme is the default without a stated brand reason
`app/layout.tsx` boots with no `dark` class on `<html>`, but CSS vars (`bg-background`, `text-neutral-200`) and the whole landing palette assume dark. A theme toggle exists (so R-21's hard requirement is met), but dark-as-default for a product that's not a dev tool / terminal needs a one-line reason somewhere in `DESIGN.md` or a comment near the `<html>` tag. Candidate reasons: audience is security researchers (dev-tool-adjacent), the data visualization uses emerald which pops better on dark. Pick one, write it down.

### 10. R-25 — Low-contrast text requires verification
Multiple instances of `text-neutral-500` / `text-neutral-600` / `text-neutral-700` on `bg-neutral-950` surfaces. Examples: `hero.tsx:106,129` (eyebrows and labels), `features.tsx:46` (code tag), `receipts.tsx` (footer-ish copy). WCAG AA requires 4.5:1 for normal text. These may well pass — the Tailwind neutral stops at 950-vs-500 are usually around 7:1 — but there's no verified check. Run the `contrast-check.py` from `antislop-human` across these pairs before shipping any new copy at those weights.

### 11. R-31 — Reasons written down (keystone rule, project-wide)
The code is mostly uncommented at the design-decision level. Specific gaps:
- Why the emerald accent (vs. any other color)?
- Why lowercase H1 in the hero (`hero.tsx:26`)?
- Why mono for every number but sans for prose?
- Why 56px grid pitch (`shared.tsx:53`)?

Each needs a one-line comment in the file where the decision lives. The `shared.tsx` file is already a good example — two "ponytail: removed per slop audit" lines explain removals. Add equivalent "ponytail: kept because X" lines for the decisions that stayed.
