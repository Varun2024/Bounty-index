## Resolution (fixed 2026-11-01)

Note: the initial list above under-sampled the em-dash scan (a truncated grep). On "all",
a full scan found the pattern was **site-wide** (RSS feeds, Discord output, the shared null
formatter, and several pages the first pass missed) — plus a few em dashes introduced earlier
this same session (llms.txt, the Dataset schema name, the per-program FAQ answers, the
wildcard/platform answer leads, the stats FAQ). All were fixed. Code comments were left alone
(R-02 governs user-facing copy; comment hygiene is the antislop-code skill's job).

Fix conventions used:
- Prose em dash → period, comma, colon, or parentheses per context (R-02).
- Null/"empty" glyph `—` → middot `·` (keeps the existing compact-cell convention without
  the banned character). Applied centrally in `lib/format.ts` plus per-caller fallbacks.
- Title separator `X — brand` → `X · brand` / `X: brand` (matches titles that already used `·`).
